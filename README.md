# Professional Nursing Portfolio

A responsive green-themed static portfolio website for a professional nurse.

## Folder structure

- `index.html` — all website content/sections
- `css/style.css` — design and responsive styling
- `js/script.js` — menu, animations and small interactions
- `images/` — profile and gallery photos
- `documents/cv.pdf` — your CV

## Personalization

Search for square-bracket placeholders such as `[YOUR NAME]`, `[EMAIL ADDRESS]`, `[YEAR]`, etc. in `index.html` and replace them with your information.

Replace:
- `images/profile.jpg` with your professional portrait
- `images/gallery-1.jpg`, `gallery-2.jpg`, `gallery-3.jpg` with your own images
- `documents/cv.pdf` with your CV

## GitHub Pages

1. Create a new public GitHub repository.
2. Upload `index.html`, the `css`, `js`, `images`, and `documents` folders.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide the published website address.

Never publish patient records, confidential medical information, or private personal documents.
